# LocalLaunch — Dehradun Web Studio

Next.js portfolio website for selling websites to tuition centres, grocery stores, stationery shops, and other local businesses in Dehradun.

## Cloudflare Pages deployment
- Framework preset: Next.js (Static HTML Export) or None
- Build command: `npm run build`
- Build output directory: `out`
- Root directory: leave blank

Before publishing, replace the demo WhatsApp number `919876543210` and `hello@locallaunch.in` in `app/page.tsx` with your own contact details.

Sample business designs are concept demos, not real client projects.
